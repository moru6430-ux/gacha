> 当前阶段（用户数 < 100）什么都不要做；先把内容和社区做厚。

## 阶段路线

```
Phase 0  ─────────  联盟分成（现在）
  │                 零成本，等用户量
  ▼
Phase 1  ─────────  卖家促销位（500+ 真实用户后）
  │                 收钱但不涉及交易资金
  ▼

  ▼

                    真正的电商模式，但需要公司主体
```

## Phase 1 · 卖家促销位（用户起量后开第一枪）

**模式**：listing 默认免费发布，卖家想"擦亮"或"置顶"付费。

**关键点**：
- 我们只收"广告费"，不碰交易资金 → **不需要支付牌照**
- 注册个体户或小公司就能收钱
- 月费定价：基础擦亮 9.9 元 / 顶部置顶 39 元 / 矿物详情页推荐位 99 元

## Phase 2 · B2C 商家会员（中期最稳）

**模式**：
- 普通用户 C2C 永远免费
- 真正的宝石商家入驻收年费（499 / 1999 / 9999 三档）
- 卖点：「认证商家」徽章 + 多发布配额 + 店铺主页 + 优先审核

**关键点**：
- 也是订阅收入，**不需要支付牌照**（只是会员费）
- 一年 200 个商家 × 平均 1500 = 30 万营收
- 已经准备：`sellers` 表设计在 `smooth-weaving-whale.md` 的 Phase 4 里

## Phase 3 · 担保交易（终极玩法，最难）

**模式**：买家付款 → 平台暂存 → 卖家发货 → 买家确认 → 平台扣 2-3% 后放款。

### 红线（必须遵守）

**❌ 不能做**：自己开发"虚拟账户"压用户的钱再转付——这叫**资金清算**，需要央行《支付业务许可证》。全国 200 来家持牌机构，普通人申请不到，违规直接刑责级别。

**✅ 必须做**：接持牌第三方的**分账系统**。

### 第三方分账服务对比

| 服务商 | 适合 | 费率 | 备注 |
|--------|------|------|------|
| **连连支付** | 国内电商 | 0.6-1.2% | 业内最稳，闲鱼前期用过 |
| **易宝支付** | 跨境 + 国内 | 0.8-1.5% | 跨境强 |
| **汇付天下** | 国内 | 0.6-1.0% | 老牌 |
| **Stripe Connect** | 跨境 / 国际 | 2.9% + $0.30 | 不接受国内 |
| **PingPong** | 跨境收款 | 0.5-1% | 适合跨境 B2C |

### 抽成数学

```
单笔 1000 元交易，咱们抽 X%：
  收入       = 1000 × X%
  分账费     = 1000 × 1%  （连连）
  支付通道费 = 1000 × 0.6%（微信 / 支付宝商户）
  服务器分摊 = 0.05 元
  ─────────────────────────
  净利       = 1000 × (X% - 1.6%) - 0.05

  X = 0.1% → 净利 -15.05 元（每笔亏 15 元）
  X = 1.5% → 净利 -1.05 元（每笔仍亏一点）
  X = 2.0% → 净利 +3.95 元
  X = 2.5% → 净利 +8.95 元（行业合理水位）
  X = 3.0% → 净利 +13.95 元（淘宝主板水位）
```

**结论**：**最低 2.5%**。3% 是健康水位。0.1% 会让平台立刻倒闭。

### 法律 / 合规清单

- [ ] **公司主体**：海南个体户（最便宜 ~1k/年）、深圳有限公司（~5k/年）、香港公司（~5k 港币/年）
- [ ] **ICP 备案**（约 20 天，免费）—— 域名指向境内服务器才需要
- [ ] **ICP 经营许可证**（约 60 天 + 5-10k 代办费）—— 有商业交易就需要
- [ ] **公安联网备案**（约 10 天）
- [ ] **等保 2.0 测评**（~3 万）—— 有用户数据 + 交易，二级
- [ ] **用户协议 + 隐私政策 + 售后争议处理流程**（找律所拟稿 ~5k）
- [ ] **税务登记**（线上线下走完整流程）
- [ ] **对接分账服务商**（连连开发对接 ~1-2 月）

### 总成本预估

| 项 | 一次性 | 年度 |
|----|--------|------|
| 公司注册 | 1000-5000 | 1000-3000 |
| ICP 经营许可证 | 5000-10000 | — |
| 等保测评 | 30000 | 10000（每年复测） |
| 法律服务 | 5000 | — |
| 分账接入 | 0（人力外） | — |
| **合计** | **~50000** | **~13000** |

加上一两个月的开发人力。**所以只有当月 GMV 真的能撑得起这些开销时再做**。

### 触发条件（什么时候开始 Phase 3）

- ✅ 月 GMV 超过 **50 万人民币**（持续 3 个月）
- ✅ 月活买家 **1000+**、活跃卖家 **100+**
- ✅ 私下交易里至少 30% 用户主动问"能不能在平台付款"

低于这条线不要碰。先把 Phase 0-2 做厚。

## 海外路线（如果你想跳过国内合规）

如果你考虑只服务海外用户、或者跨境用户：

- 注册 **美国 LLC**（特拉华 / 怀俄明，~$500，每年 ~$300 维护）或 **香港公司**（~5000 港币 / 年）
- 接 **Stripe Connect**（marketplace 模式，需 Stripe 审批，通过率挺高）
- 抽成 2.9% + $0.30/笔（Stripe 直接拿）+ 咱们自己加 1-2%
- 不需要 ICP / 等保等等中国合规
- 但收款入境涉及税务、外汇——找懂跨境的会计师（~$1000/年）

适合：定位海外 + 跨境收藏家市场，舍弃国内市场。
